# Food Delivery Data Analysis Dashboard | <b>Power BI</b>

## Project Overview :

This project is a Power BI dashboard built to analyze food delivery order data and identify meaningful patterns in customer orders, food demand, membership types, payment methods, delivery performance, and monthly order trends.

The source data was provided through multiple Excel datasets:

* Customer Details
* Restaurant Details
* Food Details
* January Sales Data
* February Sales Data
* March Sales Data
* April Sales Data

The separate datasets were connected through relationships in Power BI to create a structured data model for analysis.

## What the Dashboard Analyzes :

The dashboard provides an interactive view of:

* Total Quantity
* Total Orders
* Average Quantity per Order
* Delivery Rate
* Cancellation Rate
* Total Customers
* Monthly Quantity Trends
* Monthly Order Trends
* Quantity by Member Type
* Quantity by Food Category
* Orders by Payment Method
* Top 7 Food Items by Quantity


## Key Insights :

From the available data, the dashboard can be used to identify patterns such as:

* Main Course has the highest overall quantity among the analyzed food categories.
* Samosa is the highest-quantity food item in the Top 7 analysis.
* UPI is the most frequently used payment method.
* Monthly order and quantity trends show changes in demand between January and April.
* Gold and Regular members can be compared to understand differences in food-category demand.
* Delivery and cancellation rates provide an operational view of order fulfillment.
* Interactive filters allow the same metrics to be analyzed for specific months, member types, food types, payment methods, and restaurant types.

## Power BI Work Covered :

This project includes practice in:

* Data understanding and preparation
* Excel data integration
* Data modeling
* Table relationships
* DAX measures
* KPI cards
* Bar and column charts
* Line charts
* Donut charts

## Skills :

This project Skills practice :

*  <b>Power Query</b>
* <b>Power BI</b>
*  <b>Data Modeling</b>
